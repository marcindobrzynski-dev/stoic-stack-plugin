# Context — Stoic Stack

Ubiquitous language for the Stoic Stack plugin. Terms here are canonical: code,
docs, and prompts use these words with exactly these meanings.

## Terms

### Autopilot

The state the plugin exists to detect: the **user has stopped thinking about
the work** — short prompts without ideas, plans, or constraints, while changes
keep landing. Autopilot is a property of the _user's input_, not of the
machine's output. Delegating a large task to parallel agents is **not**
autopilot by itself; a deliberate, planned fan-out is normal engineering.

### Stoic Pause

A short reflection moment surfaced in the main conversation when the engine
decides the user is drifting into autopilot. Offers Reflect / Skip / Defer.

### Turn

One user-prompt-to-Stop cycle in a Claude Code session. The turn boundary is
the `Stop` hook — the single point where scoring and pause decisions happen.

### Turn Group

The summary of one turn built from the session event log at Stop: the prompt,
the edits (files, line counts, delegation attribution), and sub-agent
lifecycle events.

### Score

The running measure of autopilot drift. Decays over time with a half-life;
rises with each turn's signals (edit volume, low prompt effort); drops when
the user asks genuine questions. Crossing the threshold makes the turn a
pause candidate.

### Prompt Effort

A heuristic for how much thinking a prompt shows (constraints, plans, paths,
structure). The primary autopilot signal: low effort raises the score.

### Trigger

Why a pause candidate fired: `score` (soft gate — score crossed the
threshold), `critical_path` (hard gate — a watched path was touched), or
`manual` (the user asked for a reflection).

### Critical Path

A configured path keyword whose touch hard-triggers a pause candidate,
bypassing the score. For files where an unnoticed decision hurts most.

### Classifier (Veto Gate)

LLM #1 — a cheap headless call made only when a gate fires. Labels the turn
with a decision subcategory and vetoes the pause when no real decision was
found (`decision_found` false), confidence is low, or the area is disabled.

### Outcome

What the user did with a pause: `keep` (decision stands), `correct` (decision
revised), `skip` (not now), `defer` (later). The vocabulary is the choice
menu the user picks from.

### Decision

A kept or corrected reflection, persisted to the decision bank.

### Decision Bank

Per-day, per-branch markdown files of recorded decisions in the project's
`.stoic/decisions/` — the durable trace of what was decided and why.

### Fingerprint Mute

After a pause, the same category + touched-files combination is muted for a
window, so one decision isn't re-litigated turn after turn.

### Category Mute

After three consecutive skips in a category, the whole category is muted for
a longer window — the user has said "not this topic right now."

### Preset

A named sensitivity bundle mapping to scoring knobs: `calm` (rare pauses),
`balanced`, `vigilant` (frequent). The team default lives in shared config; a
personal choice overrides it.
